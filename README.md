# Futuristic Startup Name Generator

A sleek React + Tailwind CSS experience that crafts random futuristic startup names by combining bold adjectives, tech-flavored nouns, and sci-fi suffixes. Powered with Framer Motion animations, responsive styling, and a handy copy-to-clipboard action.

## Features
- 🎲 Generate a new futuristic startup name with a single click.
- ✨ Smooth Framer Motion transitions and animated controls.
- 📋 Copy the current name to the clipboard instantly.
- 📱 Fully responsive layout with a neon-glow aesthetic.

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
4. Preview the production build locally:
   ```bash
   npm run preview
   ```

> **Note:** This project was bootstrapped manually with Vite to meet the environment constraints.
